# 訪れた国

行った国・住んだ国・都市・旅行の日付を記録する、オフラインで使えるWebアプリ（PWA）。
記録は端末の中（IndexedDB）だけに保存されます。

- 地図: [world-atlas](https://github.com/topojson/world-atlas)（Natural Earth）
- 国名: [world-countries](https://github.com/mledoze/countries)
- 都市: [GeoNames](https://www.geonames.org/) cities15000（CC BY 4.0）
- ライブラリ: D3, topojson-client
